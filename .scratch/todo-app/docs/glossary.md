# Glossary

## Core Concepts

- **Task (or To-Do Item)**: The fundamental unit of work within the application. Each task represents a single item to be completed.
- **Priority**: A classification level assigned to a task to indicate its relative importance (Low, Medium, High).
- **Completion State**: A boolean flag indicating whether a task has been finished.

## Technical Terms

- **Axum**: A web application framework for Rust that is built on top of the Tower service abstraction and the Tokio runtime.
- **Astro Islands**: A design pattern where individual components are hydrated with JavaScript on top of a static HTML foundation, allowing for highly efficient, interactive UI elements.
- **Islands**: The specific interactive components (like the To-Do list) within an Astro project.
- **REST (Representational State Transfer)**: An architectural style for providing standards between computer systems on the web, implemented here via HTTP and JSON.
- **SQLite**: A C-language library that implements a small, fast, self-contained, high-reliability, full-featured, SQL database engine.
- **TypeScript**: A strongly typed programming language that builds on JavaScript, used for the frontend to ensure type safety and better developer experience.
